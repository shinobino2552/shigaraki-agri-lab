# 信楽農業研究会 🌱

農業・経済・地域のこれからを、講義、対話、現場での実践を通じて共同で研究するためのリポジトリです。

ここは **研究会としての独立した記録・考察・合意形成の拠点** です。特定の考察を最初から結論として固定せず、問い、証拠、仮説、異なる見方を残しながら育てていきます。

## 研究の柱
- **農業経営と経済**：小規模農業、地域の土地、事業の持続性
- **お金と取引**：既存の経済を分解して理解する
- **新しい経済**：「やりたい」から始まる仕組み、共鳴・コミュニティ・コミュニオン
- **道具と共同知**：AI、GitHub、Obsidianなどによる記録、参照、検証

## 記録の入口

| 場所 | 用途 |
| --- | --- |
| [00_inbox](00_inbox/README.md) | 気づき、問い、提案、未整理の資料 |
| [10_meetings](10_meetings/README.md) | 講義、研究会、議事録と合意 |
| [20_research](20_research/README.md) | 農業経済・新しい経済などの考察 |
| [30_practice](30_practice/README.md) | 現場での実践と検証 |
| [40_rules](40_rules/README.md) | 共同編集、検証、公開・合意のルール |

はじめて記録する場合は、[研究会記録テンプレート](10_meetings/TEMPLATE.md) または [研究テーマ一覧](20_research/topics.md) から始めてください。

## 記録を育てる流れ

1. **問いを置く**：`00_inbox/` にアイデア・資料・疑問を記録
2. **話す・調べる・試す**：会合を `10_meetings/`、研究を `20_research/`、現場を `30_practice/` に記録
3. **根拠を確かめる**：事実・解釈・提案・合意を分ける
4. **PRで共有する**：ブランチで変更を提案し、レビューを経て `main` に反映

このリポジトリに書かれた考察は、明示されない限り研究会全体の公式見解を意味しません。
