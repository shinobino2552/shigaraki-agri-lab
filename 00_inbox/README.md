# 00_inbox | 気づき・提案

研究会に持ち寄られた問い、アイデア、資料候補を置く入口です。

## 記録の目安
- **日付**：いつ出た話か
- **題目**：何についてか
- **発案者・記録者**：公開に同意がある場合のみ記載
- **内容**：事実・発言・解釈を分けて記載
- **出典**：資料名やリンク、参照元
- **次の行動**：調査・討議・実践・保留

ここにある内容は、研究会の正式な合意や確定事項ではありません。

議論を経て、講義記録は `10_meetings/`、研究内容は `20_research/`、実践記録は `30_practice/` に整理します。
