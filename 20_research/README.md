# 20_research | 農業・経済の共同研究

研究会で調べ、議論し、継続して育てていく知識の場所です。

## 研究テーマ（初期案）
1. **農業経営と経済**：農業の経営手法、費用、収益、地域の土地を守る仕組み
2. **お金とは何か**：貨幣、取引、信用、既存経済の仕組み
3. **新しい経済**：共鳴・コミュニティ・コミュニオンと最小取引
4. **AIと共同記録**：AI、GitHub、Obsidianを使った研究と検証

## 記述の区分
- **事実**：出典を添えて確認できる内容
- **仮説**：考察や試験的なモデル
- **意見**：特定の提案者の立場
- **合意**：研究会で確認できた事項（確認日・方法を記す）

[研究テーマ一覧](topics.md) を入口に、テーマごとの記録を増やします。
