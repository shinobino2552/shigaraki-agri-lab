# 40_rules | 記録と共同編集の運用

## 基本原則
1. このリポジトリは **信楽農業研究会の独立した記録の場** とする。
2. 提案、個人の見解、調査中の仮説と、研究会で確認された合意を混同しない。
3. 原則として **ブランチ → Pull Request（PR） → レビュー → mainへマージ** の順に編集する。
4. PRには変更目的、根拠、確認してほしい点を記載する。合意が必要な内容は確認者や確認方法も記載する。
5. 未検証の事実や人名・個人情報は扱いを慎重にする。参加者や対象者の了承なく公開しない。
6. `main` はこの研究会リポジトリ内の共有版であり、外部リポジトリの正本を自動的に変更するものではない。

## 記録の流れ
- `00_inbox/` で問い・提案を受ける
- 話し合った経緯を `10_meetings/` に記録する
- 調査・考察を `20_research/` にまとめる
- 現場の試行を `30_practice/` に残す
- 運用ルールと合意の扱いをここに記す

## 他のリポジトリとの関係
`shinobino2552/mono-gatari-repo` とは必要に応じて参照リンクやPRを通じて接続するが、**同期・自動転記・正本移動は行わない**。双方の文書を更新する場合は、それぞれの根拠とレビューを残す。
