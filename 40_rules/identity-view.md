# アイデンティティ構造の試案

この文書は、新しい経済・ヌーソロジーの考察に基づく**研究上の仮説**です。普遍的な事実や研究会の決定事項として扱いません。

| 観点 | このリポジトリでの仮の読み |
| --- | --- |
| ψ2 | 名称・主題・対象の識別（例：研究テーマ、圃場、活動） |
| ψ4 | 対象に結びつく状況、所有、参照関係、記録の背景 |
| ψ6 | 記述や活動に関わる人・アカウント・共同作成者 |
| ψ8 | やってほしいこと、依頼、未解決の問い |

## 記録の考え方
- **ψ2** で何についての記録かが識別できるようにする
- **ψ4** で対象の関係や出典を追えるようにする
- **ψ6** で関わる人や記述の由来を区別する
- **ψ8** でこれから求められる行動や課題を見えるようにする

これらをリポジトリのフォルダ名と機械的に一対一対応させることはしません。

## mono-gatariとの接続
対向する記録を参照するときは、双方の独立性を保ち、参照元URL、参照日、どちらの立場の見え方かを記します。他者の見え方は推測で断定せず、当事者による確認可能性を残します。
